# Hide and Survive

Первая версия проекта на Godot 4.4.1.

## Игровая основа
- 1 игрок и 4 NPC-напарника против одного NPC-монстра.
- Раунд длится 5 минут; монстр выбирается случайно.
- Четыре монстра с индивидуальными атаками и поведением.
- Лобби, магазин классов и предметов, монеты и сохранение прогресса.
- Горизонтальная ориентация; Android APK включает ARMv7 и ARM64.
- 3D-графика создаётся процедурно, чтобы не требовать тяжёлых внешних моделей.

## Сборка APK
GitHub Actions собирает debug APK после каждого push в `main`.
Открой вкладку **Actions**, выбери успешный запуск **Build Android APK** и скачай artifact **HideAndSurvive-Android-APK**.

## Важно
Это стартовая игровая версия, а не финальная AAA-графика. Для Samsung Galaxy A13 используется GL Compatibility и упрощённые 3D-модели. Следующие обновления могут добавлять анимации, звуки, больше локаций, баланс и дополнительные поведения NPC.
